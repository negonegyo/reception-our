# 受付番号スキャナー（PWA）

## GitHub Pagesで公開
1. GitHubで新しい **Public** リポジトリ `reception-ocr` を作成。
2. このフォルダ内の `index.html`, `app.js`, `sw.js`, `manifest.webmanifest`, `icon.svg` をリポジトリのルートへアップロード（ZIPそのものはアップロードしない）。
3. リポジトリの Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save。
4. 数分後 `https://ユーザー名.github.io/reception-ocr/` をiPhoneのSafariで開く。
5. Safariの共有メニューから「ホーム画面に追加」。

## 操作
- カメラで1枚ずつ撮影、または写真を複数選択。
- 番号の列に合わせて「左端」「右端」のスライダーを調整。初期値は画像右側を切り出します。
- OCR開始。認識番号の一覧と件数を確認し、必要なら編集・削除・手動追加。
- 送信先を入力し「メールで共有」→ iOS共有シートの「メール」を選択。**宛先はメールアプリで確認・入力が必要**。
- 「CSVを保存」で直接保存も可能。

## 制限・注意
- OCRにはTesseract.js v5を使用。初回はCDNから読み込むためネット接続が必要です。Safari/PWAでの完全オフライン動作は保証しません。
- OCRは誤認識・読み落としがあるため、必ず原画像と照合してください。画像内の4桁の数字を候補として認識するため、受付番号以外の4桁数字も拾う場合があります。
- CSVは標準的な `"0001"` 形式で出力します。Excelで直接開くと先頭ゼロが消える場合があるため、Excelの「データから取り込み」で列を文字列として指定してください。
- 重複は番号単位で除去します。重複が意味を持つ場合は不適切です。
- 画像・OCR結果はGitHubにアップロードしません。OCRエンジンのコード・モデルは外部CDNから取得します。
- GitHub Pagesの公開リポジトリはソースコードが公開されます。画像・受付番号・メールアドレスをリポジトリに含めないでください。
- iOSの共有APIでは、宛先を指定してメール添付画面を直接開くことは保証できません。
- iPhone実機でのOCR精度・メール共有動作は未検証です。
